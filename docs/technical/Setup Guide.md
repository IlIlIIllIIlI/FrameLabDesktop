Follow the FrameLabWeb steps to set up the API.

config.properties: Add the apiUrl, publicUrl, the API URI (uri=), and the API website (the site containing the login and contest pages) to the config.properties file located in the resources folder.

    Note: If hosted on localhost, the URI is: [http://localhost.local](http://localhost.local)

Placeholder links are provided with a functional API and website if you do not wish to host your own.
